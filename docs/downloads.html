  1. 下載並解壓縮

    下載完整離線包，將 ZIP 解壓縮到自己方便找到的資料夾。

    開啟資料夾裡的 「開始遊戲.html」，以 Chrome、Edge 或其他支援的瀏覽器遊玩。

  3. 之後直接離線玩

    保留資料夾，下次再雙擊同一個遊戲檔。不需要再次下載。

iPhone／iPad 使用方式

  1. 使用 Safari 連網開啟本下載頁，保持網路連線。
  2. 按「準備手機／平板離線遊玩」，等待成功提示。
  3. 點「返回遊戲」，將遊戲網址加入書籤；之後使用同一個瀏覽器開啟。
  4. 若另使用主畫面捷徑，須在該視窗確認離線準備完成。不同裝置的儲存空間可能分開。
